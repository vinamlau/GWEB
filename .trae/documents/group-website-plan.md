# 集团公司网站开发计划

## 📋 项目概述

创建一个现代化、简约风格的集团公司官网，展示三大核心业务板块：
- 边缘算力业务（CDN 等）
- 支付金融业务（支付宝、微信、银行等）
- 电商业务（公域与私域等）

## 🎨 设计风格

- **风格定位**：简约现代、专业大气
- **配色方案**：
  - 主色调：科技蓝 (#2563EB)
  - 辅助色：金融绿 (#10B981)、电商橙 (#F59E0B)
  - 中性色：白、灰、黑
- **设计原则**：
  - 清晰的视觉层次
  - 充足的留白
  - 简洁的图标和图形
  - 响应式设计

## 🏗️ 技术栈

### 前端
- **框架**：React 19 + TypeScript
- **构建工具**：Vite 6
- **UI 库**：Tailwind CSS + Headless UI
- **动画**：Framer Motion
- **图标**：Lucide React
- **路由**：React Router v7

### 部署
- **平台**：Vercel
- **域名**：需要配置自定义域名
- **CI/CD**：GitHub Actions + Vercel 自动部署

## 🎯 开发阶段

### 阶段一：项目初始化（1-2 天）
1. 创建 React + Vite + TypeScript 项目
2. 安装依赖（Tailwind CSS、React Router、Framer Motion 等）
3. 配置项目结构和基础组件
4. 设置 Vercel 部署

### 阶段二：基础组件开发（2-3 天）
1. 布局组件
   - Header（导航栏）
   - Footer（页脚）
   - Layout（布局容器）
2. UI 组件
   - Button（按钮）
   - Card（卡片）
   - Section（区块）
   - Container（容器）
3. 业务组件
   - ServiceCard（业务卡片）
   - FeatureItem（特性项）
   - StatCard（数据卡片）

### 阶段三：页面开发（3-4 天）
1. 首页开发
   - Hero 区域
   - 业务板块展示
   - 核心优势
2. 业务页面开发
   - 边缘算力页面
   - 支付金融页面
   - 电商业务页面
3. 其他页面开发
   - 关于我们
   - 新闻动态
   - 联系我们

### 阶段四：设计与优化（2-3 天）
1. 响应式适配
   - 移动端优化
   - 平板适配
2. 性能优化
   - 代码分割
   - 图片优化
   - 懒加载
3. SEO 优化
   - Meta 标签
   - 语义化 HTML
   - Sitemap

### 阶段五：测试与部署（1-2 天）
1. 功能测试
2. 兼容性测试
3. 性能测试
4. 部署到 Vercel
5. 域名配置
